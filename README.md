# BIOHAZARD: LAST STAND

School project in collaboration with:
John Coddy Riosa, John Marco Galarosa, and Ralli Cris Queda.

## Description
A 2D survival game inspired by classic Resident Evil and bullet-heaven games such as Vampire Survivors.

Set in a quarantined city overrun by infected creatures, players must survive endless waves using an automatically firing handgun. Defeat enemies, collect experience points, choose upgrades, and endure increasingly dangerous encounters while pursuing the highest score.

## Features

- Camera-following canvas gameplay in a large urban map.
- Zombies, hounds, mutants, and Tyrant bosses.
- Experience pickups, level-ups, and upgrade choices.
- WASD or arrow-key controls on desktop.
- Touch joystick controls on mobile.
- Pause and resume support.
- Username-based top-10 leaderboard stored locally in the browser.

## Running the game

Open `index.html` in a modern browser. Scores and usernames are saved locally in that browser; there is no online or shared leaderboard.
